PixelHop

Drop an image, get a link. GPS and camera data are stripped without re-compressing, and a photo studio edits images inside the browser. Rebuilt from PHP into a single ~16 MB Go binary after a full security audit.Lempar gambar, dapat link. Data GPS dan kamera dihapus tanpa kompresi ulang, dan studio foto mengedit gambar di dalam browser. Dibangun ulang dari PHP jadi satu binary Go ~16 MB setelah audit keamanan menyeluruh.

How I buildCara saya membangun

Four rules every project follows.Empat aturan di setiap proyek.

01

Private by defaultPrivat sejak awal

No trackers, no analytics, no data leaving the device unless the user asks. Amnesia wipes, PixelHop strips GPS, HEL.ink loads pixels only after consent.Tanpa pelacak, tanpa analitik, tidak ada data keluar kecuali pengguna memintanya. Amnesia menghapus, PixelHop membuang GPS, HEL.ink memuat pixel hanya setelah izin.

02

Yours to hostBisa di-host sendiri

Open source, MIT licensed, and documented well enough that anyone can run their own copy, on their own domain.Open source, lisensi MIT, dan didokumentasikan cukup baik supaya siapa pun bisa menjalankan versinya sendiri, di domainnya sendiri.

03

Docs are productDokumentasi adalah produk

Every repo has a bilingual README, a website, and pictures rendered straight from that website so they never drift apart.Setiap repo punya README dua bahasa, website, dan gambar yang dirender langsung dari website itu supaya tidak pernah berbeda.

04

Ship, then keep shippingRilis, lalu terus rilis

Versioned releases, changelogs, CI, Homebrew and Docker. Amnesia alone is past version 5.Rilis berversi, changelog, CI, Homebrew dan Docker. Amnesia saja sudah melewati versi 5.
